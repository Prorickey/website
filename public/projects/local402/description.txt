Local402 was built at Agentic Commerce: Build Day, a one-day hackathon during New York Tech Week 2026 run with Coinbase, Microsoft, and Tavily. In a team of two, we explored economically-aware AI agents: a privacy-focused SwiftUI desktop app that runs a local LLM on Apple Silicon with MLX, backed by a private document store using on-device embeddings and a SQLite vector search. When the agent needs fresh information, it runs a Tavily web search that is paid for as a real USDC micropayment over Coinbase's x402 payment rail on Base, with a small Node.js and TypeScript backend holding the wallet secrets.
