Distill won first place at Microsoft's Copilot hackathon during New York Tech Week 2026, a one-day build sprint at Microsoft's Midtown Manhattan office. In a team of five, we built a tool that makes dense research papers easier to understand: you upload a paper PDF through a Next.js web app, and a Node.js agent pipeline extracts the text, writes a readable Markdown summary focused on the hardest important ideas, and generates a single self-contained HTML visual that can be embedded anywhere.
